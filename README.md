# The Water - Johnny Flynn

https://sollybunny.github.io/the-water-duet-helper/

A simple page which allows you to mix the individual singers of [The Water sung by Johnny Flynn and Laura Marling](https://www.youtube.com/watch?v=a4QQ7HYYdWw).

This page is fully static and can be run with `npx run alive-server`.

If you wish to use this for your own audio the script to split audio is in `voice-sep`, it only works on two singers with distinct ranges.
